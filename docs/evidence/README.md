# Evidence

Machine-readable records of runs that reports in `docs/` cite.

| File | What it holds |
|---|---|
| `cross_simulator_evidence.json` | Every scenario of the Fabrivium vs Siemens Plant Simulation comparison: the handoff verification, both engines' figures, the difference, and the preregistered tolerance applied to it. Written by `backend/scripts/cross_simulator_validation.py`. |

**One edit was made before publishing.** Four absolute Windows paths to the
generated `.spp` files were shortened to their file names. Nothing else was
changed, and no figure was touched.

The `.spp` models themselves are not in the repository. They are 3.7 MB each
and are regenerated by the harness on a machine that has Plant Simulation 2404.

Read the results with
[the cross-simulator validation report](../CROSS_SIMULATOR_VALIDATION_REPORT.md),
and the rules they were scored against with
[the preregistration](../CROSS_SIMULATOR_VALIDATION_PLAN.md).
